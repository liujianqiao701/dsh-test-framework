## §2 连上立刻自证「没连错」（**不许跳**）

```sql
select current_database() as db, current_user as usr,
       host(inet_server_addr()) as server_ip,   -- ★ 关键：能证伪"连错机器"
       inet_server_port() as port, version() as ver, current_schema() as cur_schema;
select nspname from pg_namespace               -- 该系统的特征 schema
 where nspname not like 'pg_%' and nspname <> 'information_schema' order by 1;
```

| 现象 | 含义 / 动作 |
| --- | --- |
| `host(inet_server_addr())` 与用户给的 host **不一致** | **最常见事故**：以为连远程、其实是本地副本（连 `127.0.0.1` 就返回 `127.0.0.1`）→ **立刻停**，回头问用户 |
| `current_database()` 不是用户说的库名 | 给错库，或连到了同名库 → 停下来对 |
| schema 清单里没有该系统的特征 schema | 很可能连错了系统 → 停下来对 |
| 全部对得上 | 把这段结果**原样记进报告**，作为"我连的是哪个库"的证据 |

## §3 全量扫描表结构与关联（只读，扫一次落盘复用）

扫什么：表（表名 / 注释 / 行数估算 / 大小）、列（名 / 类型 / 长度 / 可空 / 默认值 / 注释）、主键与唯一约束、**外键**、索引、**推断关联**（同名列 / `xxx_id`·`xxx_code` 命名规约 / 注释提及）。
落盘三件套（下次直接读，不必重扫）：`tables.json`（全量结构）、`relations.json`（关联）、`结构.md`（人读摘要 + 关联清单），建议目录 `<产品>\_库结构\<host>-<dbname>\`；**重扫前先问用户**。

> ⚠️ **实测这类业务库常常一条外键约束都没有**（`information_schema.table_constraints` 里查不到 `FOREIGN KEY`）。
> 关联只能靠**同名列 + 命名规约 + 表注释 + 业务口径**推断，且**必须把推断依据写下来**；无外键时造数顺序按**推断拓扑**排（父表先、子表后）——
> **别指望"数据库会拦住你"，它不会，孤儿行会安静地插进去。**

## §5 主键与序列（三个必踩的坑）

1. **主键一律动态侦测（按数值最大算），禁止写死**；字符串主键必须先过滤再 CAST，否则遇到 `INVGEN_001` 会把 CAST 打挂：
   `select max(cast(pkid as bigint)) from <表> where pkid ~ '^[0-9]+$';`
   只有两种安全写法：**① 动态算（首选）**；**② 清空重建 + 复位序列** —— `TRUNCATE TABLE <表> RESTART IDENTITY CASCADE`，插完**必须**复位序列，否则后续 INSERT 从 1 重来、撞上已有行。
2. **修序列脱节的正确写法**（**不动任何数据行**）：`select setval('<真序列名>', (select max(<主键>) from <表>), true);`
3. **判据必须取列默认值里写的那个序列**，**别信 `pg_get_serial_sequence`**（本机实测它有返回**废弃 `_seq1`** 的坑）：

```sql
select a.attname, pg_get_expr(d.adbin, d.adrelid) as col_default   -- 从 nextval('...') 里取真序列名
  from pg_attrdef d join pg_attribute a on a.attrelid = d.adrelid and a.attnum = d.adnum
 where d.adrelid = '<schema>.<表>'::regclass and a.attname = '<主键列>';
```

## §6 只读诊断的红线

> ⚠️ **只读诊断里永远不要调 `nextval()`** —— 它**非事务性**，`rollback` **撤不回**，会真实推进序列、在共享库上凭空吃掉号段。
> 要看下一个值就用 §5 第 2 条的 `max()` + `setval` 反推，或只读 `pg_sequences.last_value`。
