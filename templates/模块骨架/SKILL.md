## §5 本模块资料

- `requirement\`：需求原文（**只读**）
- `skill\<版本>\SKILL.md`：**各版本规范**（测试要点 / 造数逻辑 / 坑清单，一版一份，互不覆盖）
- `final\`：整理稿 / 口径 / 规范 / `<版本>-{{MODULE}}造数逻辑.md`
- `report\`：测试报告（含本模块冒泡报告、取消项核对报告）
- `data\`：测试数据 / 素材 / 证据（含 `冒泡测试-<日期>\`、`需求测试-<日期>\`）
- `scripts\`：（**按需建**）本模块专属脚本 —— 会长期复用的流程才放这里，一次性脚本用完移 `_archive\scripts\`

> ⚠️ 翻历史先看本文件末尾「## 归档索引」与 `_archive\报告归档\{{MODULE}}\_归档索引.md` ——
> 上面 §5 是静态清单，报告与证据满 24h 后路径必然失效（归档是动的）。

## §6 产出约定

- 需求原文进 `requirement\`（**只读**，不改写）；整理稿/口径/规范进 `final\`（文件名带 `_AI整理` 或版本号）
- 测试报告进 `report\`，命名 `{{MODULE}}-<内容>-<yyyyMMdd>.md`
- **报告怎么写：照 `_templates\测试报告模板.md`，它是硬要求** ——
  ① **结论先行**（§一 结论 + §二 缺陷速览表在最前，不看下文就知道几条、哪条最严重）；
  ② **一条缺陷一小节**、字段固定、**每条 ≤ 20 行**，禁止长篇散文；
  ③ **每条缺陷必须写「需求原文依据」**（文档名 + 章节号 + **原文引用**），需求确实没写的写
  `需求未明确`，**不许拿猜测当依据**；
  ④ **「与需求不符点」单独一行点明**差在哪个字段/分支/文案/口径；
  ⑤ 大段日志/报文/SQL **不进正文**，落 `data\` 只写路径。
- 测试数据/导入文件/导出结果进 `data\`；**不要丢在框架根目录**
- 产出**不越界**：本模块的东西只落本模块目录

## §9 需求文档与「划掉项」核对（**按版本**）

规范：框架级 skill **`requirement-docs`**（自动加载；**划掉的不读，但要查**）。

- **本模块需求文档**：`<文件名 + 版本>` —— 在需求文档**总根目录** `{{REQ_DOC_ROOT}}\<系统>\` 下
  （**一个子目录 = 一个系统**；**新版本需求也放同一目录** → 用前先判版本；密码见 `{{PRODUCT_DIR}}\_框架配置\环境与账密.md`，**不写进本文件**）。
  **只知道"哪个系统的哪个文档"时别猜路径**，先定位：
  `python skills\requirement-docs\scripts\find_req_doc.py --list`（看系统清单）/
  `... find_req_doc.py --query "<关键词>" --system <系统>`（列全部候选：主线 / 版本子目录 / 历史备份 / 草稿，**默认取主线**）
- **抽取产物**：`data\需求测试-<yyyyMMdd>\`（`req_src\` 原文副本 / `req_decrypted\` 解密件 / `text\` 正文 + 划掉清单 + blocks.json / `取消项核对表-<文档>.md`）
  一键命令（**定位 + 解密 + 抽正文 + 出核对表**）：
  `python skills\requirement-docs\scripts\prep_requirement.py --system <系统> --find "<关键词>" --module {{MODULE}} --password <密码> --version <版本>`
  （已知道确切路径就换 `--src "<加密文档或目录>"`；命中多份用 `--pick N` 指定，别猜）
- **正文 = 需求**（已跳删除线/修订删除）；**划掉项 = 已取消，不当需求读** —— 不许拿它当"应该有的功能"去提缺陷
- **但取消项必须回头核**：逐项到测试环境确认「系统里是不是也去掉了」，
  结论三选一：`已同步取消` / **`未取消（残留）`→提缺陷** / `无法判定`（写明缺什么，**不许含糊成通过**）
- **报告**：`report\{{MODULE}}-取消项核对-<yyyyMMdd>.md`（逐项表 + 未取消清单 + 证据路径；写明**文档版本 + 抽取时间**）
- **按版本记**：`skill\<版本>\SKILL.md` 里写该版本的文档名与章节对应关系；跨版本共用的定位方法写在本节
