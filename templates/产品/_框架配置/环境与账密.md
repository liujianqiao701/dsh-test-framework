### ⚠️ 铁律：连上先自证没连错机器

**连库第一件事**，跑：

```sql
select current_database(),
       host(inet_server_addr()) as server_ip,
       inet_server_port()       as server_port,
       current_user,
       version();
```

把返回值与**用户口述的地址、库名逐项对照**：

| 对照项 | 不一致意味着 |
| --- | --- |
| `current_database()` ≠ 用户说的库名 | **连错库** —— 立刻断开重连 |
| `host(inet_server_addr())` ≠ 用户说的 host | **连错机器**（最常见：以为连远程，其实连到了本地副本 `127.0.0.1`） |
| `inet_server_port()` ≠ 用户说的端口 | 同上（`5432` / `5433` 极易混） |
| 地址一致但**看不到预期 schema / 表** | 连对了机器、库不对，或账号权限不足 |

> **为什么写成铁律**：账号密码可以从本表取、也可以由用户口头给，但**取到的地址可能是过期的**。
> 自证这一步只花一秒，却能挡掉「在本地副本上改了半天，以为在改共享库」这类事故。

**其它硬性要求**：

1. **以 SELECT 为主**；改数据只在**造数夹具**上做，且改前先快照（见 §1 `说明` 列与 §4）。
2. **主键动态算**（`skills\db-seeding\scripts\next_key.py`，按数值最大），**禁止写死**。
3. **生产 / 共享库**：改前快照 → 改完汇报「改了什么、是否已还原」，**保留还是清理测试数据由用户决定**。
